README

Amberstone

A local, real-time coaching companion for League of Legends and Teamfight Tactics.

About this artifact

A self-contained, offline map of the Amberstone repository. Each node is a component - a module, a document, a tool, an agent or an upstream service - and the dust around it is the source files that belong to it. Hover a node for its summary, click to focus it; the controls are listed along the bottom edge. Nothing here loads from the network, so the file works on its own.

The project in one paragraph

Amberstone watches the game you are actually in, through the client's local data feed and through the screen, and turns that into short, situation-specific advice - what to build, when to fight - on a local dashboard and an in-game overlay. The build engine, Daemon Slayer, ranks items from real damage and durability numbers for the matchup at hand rather than from other players' win rates, and the AI coach reasons over that output. Screen reading is OCR first, with an AI vision model escalated only for what OCR misses. Everything runs on one Windows PC. The engine version, patch and counts in the HUD readout at the right are a snapshot taken when this page was generated, not a live feed - the repository is the current answer.

Where the real docs are

  • README.md - the project front page
  • docs/ARCHITECTURE.md - component map
  • docs/DAEMON_SLAYER.md - the build engine
  • ROADMAP.md - open work

Each one links to the file on GitHub, and each path also resolves inside a checkout. The map itself still runs entirely offline - only these links need a network.
