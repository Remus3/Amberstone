README

About this map

A map of the Amberstone repository, generated from its git index by tools/atlas_build.py. Each node is a component - a directory of source files, or a family of modules sharing a name prefix - placed in its category's sector. The dust around a node is its source files, one star per file. The lines are real structure: solid lines are Python and JavaScript imports between components, dashed lines are the directory tree. Nothing on this page is typed in by hand, so it cannot drift from the code - the HUD says which commit it was built from.

The project in one paragraph

Amberstone watches the game you are actually in, through the client's local data feed and through the screen, and turns that into short, situation-specific advice - what to build, when to fight - on a local dashboard and an in-game overlay. The build engine, Daemon Slayer, ranks items from real damage and durability numbers for the matchup at hand rather than from other players' win rates, and the AI coach reasons over that output. Screen reading is OCR first, with an AI vision model escalated only for what OCR misses. Everything runs on one Windows PC.

Controls

  • Drag pans the map; Shift+Drag (or Ctrl / Alt) tilts and turns it.
  • Scroll or pinch zooms toward the pointer, up to 12x; zoom in and every component separates into its files.
  • Click a component, a file or a category title to select it; Double-click dives in, or resets the view on empty space.
  • Esc or a click on empty space releases the selection.
  • Pause stops all motion. With the map focused: arrow keys pan, + / - zoom, 0 resets, P pauses.
