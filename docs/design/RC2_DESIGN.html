RC 2.0 - the model single-monitor, overlay-centric

One monitor. In-game, a lean glanceable HUD sits on top of League (1920 fullscreen or borderless). The full dashboard never disappears - it is one click / second window away and STAYS available while the overlay is active. Every setting is changeable without a hotkey. Three themes ship; you pick one below and it re-skins every surface live.

The overlay shows ONE primary cue + 2-3 support slots (glance budget <2s). The dashboard holds everything else and opens beside the game without stealing focus. No hotkey is required for any action - the overlay carries on-screen controls.

What changes vs today

  • Overlay no longer hides the dashboard - they coexist (your reported bug).
  • DPI/scale-aware overlay sizing - fixes the fixed-460px box; adapts to resolution. RC2_RESEARCH_overlay_sizing LIFT-C
  • Borderless detect-and-nudge instead of a silently dead HUD. LIFT-A
  • Settings without hotkeys - on-screen toggles everywhere.

In-Game Overlay the centerpiece

Presentation + priority, not a feature dump. Cues render where the eye already looks: objective ETAs near the clock and on the minimap, a single self-expiring "do now" line, a ward-ready pulse, the next item, and the A/B/C call. Click-through stays on; the dock can stay pinned or auto-hide.

Design System 3 themes, one token set

All three reskin from the same semantic tokens (surface tones, status triad, 8px grid, fs 16-46). Status is never color-only - every good/warn/bad value carries a glyph (up / down / warn) for color-blind + WCAG 1.4.1. Switch live with the buttons up top.

Hextech Tactical
League-native: slate base, hextech gold + cyan. On-brand, high-contrast for glance.
Eclipse Minimal
Near-black, single cool accent, typography-led. Calmest overlay, least distraction.
Broadcast Esports
Vivid status-driven, electric cyan + magenta. Most legible at a fast glance, busiest.
