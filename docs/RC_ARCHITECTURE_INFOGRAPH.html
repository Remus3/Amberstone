Learned Gotchas

1. Riot's APIs are localhost-only. LCU and Live Client refuse LAN connections even when bound to 0.0.0.0. Solution: relay agents on Game-PC push to Legion.
2. iphlpsvc port-proxy self-loops. Silently eats port 2999 (symptoms: SSL UNEXPECTED_EOF_WHILE_READING, curl schannel handshake fails). Check netsh interface portproxy show all first.
3. Python 3.14+ stdout is cp1252 on Windows. Agents with Unicode arrows crash on first print(). Set PYTHONUTF8=1 + PYTHONIOENCODING=utf-8.
4. Tkinter overlays were removed (T2 #6, 2026-05-01). Web dashboard at :8888 is the only UI. tk.Tk() root remains in app/__init__.py as the timer scheduler driving game polling via root.after(...).
5. Vision media-type mismatch. Screen agent pushes JPEG; Anthropic rejects 400 if media_type says image/png. Auto-detect: "image/jpeg" if data.startswith("/9j/") else "image/png".
6. Python triple-quoted strings double-escape backslashes. \[ in a JS regex inside a Python """...""" HTML template leaks through as literal \\[ in the browser. Use .replaceAll() with string literals, not regex.
