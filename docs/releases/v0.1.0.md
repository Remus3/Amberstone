# Amberstone v0.1.0

First tagged milestone. Amberstone is a local, real-time coaching companion for
League of Legends and Teamfight Tactics that runs on one Windows PC. This is a
source release: there is no installer and no packaged binary. Run it from a
checkout of this tag, as described under Install.

Tagged 2026-10-15. These notes were written by hand from
[`docs/LEDGER.md`](../LEDGER.md), the project's completion record, up to and
including its entry 1728.

## What works at this tag

- **Live game reader.** The match is read from the game client's local Live
  Client API about once a second. Gold, level, KDA and both teams' items feed
  situation-specific advice. The modes covered are Summoner's Rift, ARAM
  including its event variants, Arena, Teamfight Tactics, and Riot's rotating
  modes.
- **Daemon Slayer build engine.** Deterministic item and damage math decides
  builds and fights, and the AI coach only narrates what the engine decided.
  It covers 173 champions and 706 items at game patch 16.20.1.
- **Champion select.** Pick suggestions come from your own match history,
  filtered by the enemy composition. Ban and counter hints come from the
  engine's 1v1 damage math. Runes are written into the League client through
  its local API.
- **Vision.** OCR reads the screen first, and a vision model is called only
  for what OCR misses.
- **Dashboard and overlay.** A local dashboard on port 8888 serves HTTPS once
  a local certificate exists. An Electron overlay shows in-game advice.

## Changes in the month before this tag

- **Dependencies are locked with hashes.** `requirements.in` holds the
  top-level pins. `requirements.txt` is generated from it with
  `--generate-hashes` and covers every transitive dependency for Python 3.11
  (the embedded runtime) through 3.14, on every platform. `install.bat` was
  proven in a fresh environment on each interpreter. CI installs only hashed
  dependency sets, and the GitHub Actions it uses are pinned by commit.
- **Code scanning findings triaged.** Every open CodeQL finding was triaged.
  The fixes include HTML escaping in dashboard panels and tooltips, linear-time
  regular expressions in two parsers, and a CORS check that refuses a header
  value carrying a line break. Each finding that was not a defect is dismissed
  with a written reason.
- **Dashboard server hardening.** The TLS handshake and the plain-HTTP
  redirect run off the accept path, under one total deadline, so a silent
  client cannot stall other requests. Thread starts are capped.
- **Commit and push gates.** Commit subjects follow Conventional Commits, and
  merges read `merge: <topic>`. A push is refused on a non-operator identity,
  on another repository's name, on a credential shape, or on the checkout's
  own path.

## Install

1. Install Python 3.12 or newer and Git LFS, clone the repository, and check
   out this tag.
2. Run `install.bat`. It installs `requirements.txt` in pip's hash-checking
   mode, creates the runtime directories, and asks for an Anthropic API key.
3. Run `start.bat` and open the dashboard on port 8888.

The full steps are in the README's Quickstart.

## Known limits

- Windows only, and the game, coach, dashboard and overlay share one PC.
- The coaching and vision paths need your own model API key. Without one they
  stay off, and the local engine math still works.
- Some in-game state has no Riot API, and some event modes return no match
  history.
- Not affiliated with Riot Games.
