============================================================
DIRECT CHROME IMPORT - bypasses Windows trust store entirely
============================================================

NOTE: Game-PC left the League/RC pipeline at the 1-PC
consolidation (2026-05-29, ADR-011). The RC dashboard is now
viewed in Chrome ON Legion. This note is retained as the
Legion-local cert-import recipe.

If Chrome still shows "Not Secure" after running the cert
install step, do this instead. It writes the CA into Chrome's
own trust store (separate from Windows), so OS-level trust
issues don't matter.

------------------------------------------------------------
On Legion, in Chrome:
------------------------------------------------------------

1. Address bar:   chrome://settings/certificates
                  (or chrome://settings/security -> "Manage
                  certificates" if your Chrome version moved it)

2. Click the "Authorities" tab (NOT "Your certificates").

3. Click "Import".

4. In the file picker, navigate to the local mkcert root CA
   on Legion (generated by tools/regen_rc_cert.ps1), e.g.:
       %LOCALAPPDATA%\mkcert\rootCA.pem
   or wherever your local copy lives.

   You may need to change the file-type filter from
   "DER-encoded ..." to "All files (*.*)" so the .pem is visible.

5. A dialog appears asking what to trust. Check ALL THREE:
       [x] Trust this certificate for identifying websites
       [x] Trust this certificate for identifying email users
       [x] Trust this certificate for identifying software makers

6. Click OK.

7. Fully close Chrome:
   - Right-click the Chrome icon in the taskbar -> Close window
   - Open Task Manager, end EVERY chrome.exe (there are usually
     several background helpers)

8. Reopen Chrome, visit:
       https://legion-rc:8888/   (or https://127.0.0.1:8888/)
   You should see the padlock with no warning.

------------------------------------------------------------
Why this works when the OS install didn't:
------------------------------------------------------------

Chrome on Windows uses a hybrid trust model since version 105:
  - Chrome's own Root Store (CRS) is consulted first.
  - Windows trust store is consulted for private CAs IF the cert
    is in LocalMachine\Root AND passes Chrome's path checks.

The "Authorities" import bypasses both layers - it directly
adds the CA to Chrome's per-user trust list, no admin needed,
no policy negotiation. The trade-off: only that user profile
trusts it (per Chrome profile, not system-wide).

------------------------------------------------------------
Verify in Chrome
------------------------------------------------------------

After import, visit chrome://settings/certificates again and
look in the Authorities tab. Search "mkcert" - you should see
a single entry like:
   org-mkcert development CA
       mkcert LEGION-RC\Administrator@LEGION-RC

Right-click -> Edit -> all three checkboxes ticked.

------------------------------------------------------------
Edge users
------------------------------------------------------------

Edge uses a similar UI: edge://settings/privacy -> Security ->
"Manage certificates" -> Authorities tab -> Import. Same .pem
file, same checkboxes.
