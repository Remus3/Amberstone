OQ3 - Peripheral Objective Gauge Overlay: 3 Mockups

Static design mockups (no live wire). Each shows the four objectives - DRAKE / BARON / ELDER / SUMMS - as periphery ring / arc gauges for at-a-glance reads while playing. Pick one variant to build; the tradeoff note on each frames the choice. On-palette to the Hextech overlay doctrine.

Variant A - Radial Ring Cluster

Tradeoff: Clearest per-objective read with exact numeric ETA, but the tallest footprint (four full dials).
